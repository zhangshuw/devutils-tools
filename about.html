关于 DevUtils

一个开发者用业余时间维护的工具站。不收钱、不要登录、不上传你的数据——不是因为承诺，是因为这些工具根本不需要。

怎么开始的

2026 年初某个周末，我又一次需要解码一段 Base64。打开搜索结果第一个工具，是一个挂着两个弹窗广告的页面，输入框旁边写着"上传到云端解析"——然而 Base64 解码这事根本不需要服务器，五行 JS 就够了。

类似的事情遇到太多次：JSON 格式化要等 3 秒加载、JWT 解码站点偷偷把 token 上传、正则测试器塞满"VIP 升级"按钮。这些操作本来都该在本地浏览器里完成。我开始自己写——先是 5 个工具凑数，到这篇文章修改的时候已经 26 个了。

关于"不上传"这件事

每个工具页面右下角都说"数据不上传"——这不是宣传话术，是工程现实：

  • JSON 格式化 / Base64 / URL 编解码 / 时间戳转换 / 大小写转换——这些都是字符串操作，几行 JS 就完事
  • 哈希计算 / JWT 编辑 / 密码生成——浏览器原生支持 crypto.subtle Web Crypto API，加密强度跟后端一样
  • 图片压缩 / 二维码生成 / Markdown 预览——Canvas API、QRCode 库、Marked.js，全本地运行

反过来说：需要上传到服务器的事情我就不做。比如 IP 地理位置查询、汇率换算——那些必须调 API，可能涉及第三方数据收集，我不做这类。

关于收入

这站挂了 Google AdSense。开发工具站的 CPM 不高（开发者用 Adblock 比例高），实际收益月均几十块钱——勉强能 cover 服务器+域名。

没有 Premium 版本、没有 Pro 套餐、没有限频。免费用、随便用、嫌广告碍眼装 uBlock 我完全不介意。如果工具帮到你了，分享给同事就是最好的支持。

技术栈

纯 HTML / CSS / JS，没有任何打包工具。每个 tools/<name>.html 就是一个独立页面——直接 View Source 就能看到完整代码。这种做法在 2026 年算返祖，但好处是页面加载快（首屏 1KB CSS + 4KB HTML），代码可审计，永远不会"项目跑不起来"。

开源在 GitHub：github.com/zhangshuw。

不会做的事

  • 用户系统 / 登录——工具不需要知道是谁
  • 历史记录同步——如果非要持久化，浏览器 localStorage 够用
  • 付费功能——免费的核心是没有付费版逼你升级
  • 跟踪分析——只有 AdSense 必须的 GA 用于审计，没有自己的埋点
