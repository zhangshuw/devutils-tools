JSON 开发中的 10 个实用技巧

发布于 2026年5月21日 · 阅读时间约8分钟

JSON 是现代开发中最常用的数据交换格式。无论你是前端、后端还是全栈，每天都要和 JSON 打交道。以下 10 个技巧能让你处理 JSON 时事半功倍。

1. 一键格式化压缩 JSON

面对一行几千字符的压缩 JSON，直接手动缩进是不现实的。最快的办法是用 在线 JSON 格式化工具，粘贴即格式化，语法高亮让数据结构一目了然。反过来，发送数据前也可以一键压缩。

2. 自动检测 JSON 语法错误

JSON 报错 Unexpected token 又找不到问题在哪？常见的错误：

  • 尾部逗号：最后一个元素后面多了个逗号 {"name": "test",}
  • 单引号：JSON 只认双引号，单引号会报错
  • 注释：标准 JSON 不支持 // 或 /* */ 注释
  • 未引用键名：键名必须用双引号包裹

用 JSON 格式化工具 的验证功能可以精确定位错误行号。更详细的排查方法见 JSON 教程。

3. 用 jq 命令行处理 JSON

Linux/Mac 上处理 JSON 文件，jq 是最好的命令行工具：

# 格式化
cat data.json | jq .

# 提取字段
cat data.json | jq '.users[].name'

# 过滤
cat data.json | jq '.items[] | select(.price > 100)'

4. JSON 转 CSV

有时需要把 JSON 数据导入 Excel 分析。用 jq 一行搞定：

cat data.json | jq -r '.[] | [.name, .age, .city] | @csv'

5. 深度比较两个 JSON

接口返回的 JSON 和预期不一致？用 文本差异对比工具 粘贴两个 JSON，逐行高亮差异，快速定位变化。

6. JSON Schema 验证

生产环境中 JSON 结构必须符合规范。JSON Schema 可以在数据进入系统前做自动化校验：

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": ["name", "age"],
  "properties": {
    "name": {"type": "string", "minLength": 1},
    "age": {"type": "integer", "minimum": 0}
  }
}

7. 避免 JSON 中的常见坑

  • 大整数精度丢失：JavaScript 的 Number 只能安全表示 ±2^53 以内的整数，超出范围的大整数用字符串传
  • undefined 和 NaN：JSON 不支持这两个值，序列化时会被转为 null 或直接丢弃
  • 循环引用：对象包含自身引用时 JSON.stringify() 会报错

8. 美化浏览器中的 JSON 显示

Chrome 浏览器直接访问 JSON API 时，可以安装 JSON Viewer 扩展；或者用 JSON.stringify(obj, null, 2) 在控制台输出。

9. 安全地解析 JSON

永远不要用 eval() 解析 JSON（XSS 风险）。使用 JSON.parse() 并配合 try-catch：

try {
  const data = JSON.parse(input);
} catch (e) {
  console.error('JSON 解析失败:', e.message);
}

10. 用 Base64 传输二进制 JSON

如果要在 JSON 中嵌入二进制数据（如图片），先 Base64 编码再放入 JSON 字符串字段。
