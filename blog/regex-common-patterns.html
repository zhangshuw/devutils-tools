10 个最常用的正则表达式速查表

发布于 2026年5月21日 · 阅读时间约5分钟

写正则表达式最怕的就是把边界情况漏了。这篇文章整理了开发中最常用的 10 个正则表达式，每个都经过大量实战检验，可以直接复制到你的项目中。用 正则测试器 可以实时验证每个表达式。

用途正则表达式说明
邮箱 ^[\w\.-]+@[\w-]+\.[\w\.-]+$ 覆盖常见邮箱格式，如 name@domain.com、name.name@sub.domain.co.jp
中国手机号 ^1[3-9]\d{9}$ 匹配 130-199 号段，共 11 位
固定电话 ^0\d{2,3}-\d{7,8}$ 区号 2-3 位 + 号码 7-8 位，如 010-12345678
身份证号 ^\d{17}[\dXx]$ 18 位，最后一位可能是 X
URL 地址 ^https?://[\w\.-]+\.[a-z]{2,}(/\S*)?$ 匹配 http/https URL，不包含 URL 参数
IP 地址 v4 ^((25[0-5]|2[0-4]\d|1\d{2}|[1-9]?\d)\.){3}(25[0-5]|2[0-4]\d|1\d{2}|[1-9]?\d)$ 严格匹配 0.0.0.0 ~ 255.255.255.255
邮政编码 ^\d{6}$ 中国邮政编码为 6 位数字
日期 YYYY-MM-DD ^\d{4}-\d{2}-\d{2}$ 不校验日期有效性（如 2026-02-30 也会匹配）
中文汉字 [一-龥]+ 匹配一个或多个中文字符
16 进制颜色 ^#([0-9a-fA-F]{3}|[0-9a-fA-F]{6})$ 匹配 #FFF 或 #FFFFFF 格式

进阶版正则表达式

上面的是基础版。如果你需要更严格的校验，用下面这些：

严格邮箱校验

^[a-zA-Z0-9.!#$%&'*+/=?^_`{|}~-]+@[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?(?:\.[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?)*$

这个来自 RFC 5322 规范，能过滤 99.99% 的非法邮箱。

密码强度校验（8位+大小写+数字+符号）

^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*()_+\-=\[\]{};':"\\|,.<>\/?]).{8,}$

中国车牌号

^[京津沪渝冀豫云辽黑湘皖鲁新苏浙赣鄂桂甘晋蒙陕吉闽贵粤川青藏琼宁][A-HJ-NP-Z][A-HJ-NP-Z0-9]{4,5}[A-HJ-NP-Z0-9挂学警港澳]$

如何使用这些正则？

JavaScript

const emailRegex = /^[\w\.-]+@[\w-]+\.[\w\.-]+$/;
if (emailRegex.test('user@example.com')) {
  console.log('邮箱格式正确');
}

Python

import re
pattern = r'^[\w\.-]+@[\w-]+\.[\w\.-]+$'
if re.match(pattern, 'user@example.com'):
    print('邮箱格式正确')

Java

String email = "user@example.com";
if (email.matches("^[\\w\\.-]+@[\\w-]+\\.[\\w\\.-]+$")) {
    System.out.println("邮箱格式正确");
}
