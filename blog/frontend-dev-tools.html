作为前端开发者，每天都要处理各种格式转换、调试、测试等琐事。安装一堆桌面软件太重，浏览器插件又容易冲突。最好的方案是在线工具——打开即用，不占空间，跨平台通用。

以下是我日常开发中最常用的 10 个在线工具，全部免费，且数据在本地处理不上传服务器。

JSON 格式化工具

粘贴压缩 JSON 一键美化，自动检测语法错误并定位行号，支持压缩/格式化切换

后端返回的 JSON 经常是一行几千字符的压缩数据，肉眼根本没法读。JSON 格式化工具是前端开发中使用频率最高的工具之一。

使用场景：

  • 调试 API 返回数据，快速定位嵌套层级
  • 排查 JSON 语法错误（尾部逗号、单引号等）
  • 压缩 JSON 数据减小传输体积
🔤

Base64 编解码

文本与 Base64 互转，支持文件上传，编码解码一键切换

JWT Token 解析、Data URL 图片嵌入、API 认证头……Base64 编解码几乎是前端开发日常。详细了解原理可以看这篇 Base64 编解码教程。

🔍

正则表达式测试器

实时匹配高亮，支持捕获组显示，多行匹配模式

写正则最烦的就是来回调试。正则测试器 输入正则和文本实时匹配，捕获组一目了然。推荐收藏这份 常用正则表达式速查表。

🕐

时间戳转换器

时间戳与日期互转，支持秒级/毫秒级，一键获取当前时间戳

前后端对接时，时间戳格式不一致是常见问题。这个工具支持秒级和毫秒级互转，还能一键复制当前时间戳。

🔐

JWT 解码器

解析 JWT Token 的 Header 和 Payload，自动转换时间戳字段

调试登录、权限相关接口时，经常需要查看 JWT Token 里的内容。JWT 解码器 直接粘贴 Token 就能看到 payload，比在控制台写 atob() 方便多了。

🔗

URL 编解码

URL 编码与解码转换，处理中文、特殊字符

处理 URL 参数中的中文或特殊字符时，URL 编解码是刚需。尤其是在调试 window.location.search 或处理重定向 URL 时。

🎨

颜色转换器

HEX、RGB、HSL 颜色格式互转，实时预览

设计稿用 HEX，CSS 有时用 HSL，Canvas 需要 RGB……颜色格式转换虽然不难但很繁琐。

📊

文本差异对比

逐行对比两段文本，高亮增删改

对比接口返回的差异、排查配置文件变更、比较代码版本——文本对比工具能精确到每个字符的增删改。

🔒

密码生成器

生成高强度随机密码，自定义长度和字符类型，显示密码强度

注册测试账号、配置数据库密码时都需要强密码。详见 如何选择安全的在线密码生成器。

CSS/JS/HTML 代码压缩与美化，显示压缩比

上线前压缩 CSS/JS 减小文件体积，调试时美化压缩过的代码便于阅读。
