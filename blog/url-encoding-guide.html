URL 编码是什么？为什么要对 URL 进行编码？

发布于 2026年5月21日 · 阅读时间约7分钟

你有没有见过 URL 里的 %E4%B8%AD%E6%96%87 这种奇怪字符串？这就是 URL 编码（也叫百分号编码）。本文解释 URL 编码的原理、为什么需要它、以及什么时候该用它。

什么是 URL 编码？

URL 只允许包含一部分 ASCII 字符（字母、数字、-、_、.、~）。其他字符——包括中文、空格、特殊符号——必须编码为 % 加两位十六进制数的形式。

例如：

原始字符URL 编码
空格%20 或 +
中文"你好"%E4%BD%A0%E5%A5%BD
&%26
=%3D
/%2F

为什么需要 URL 编码？

URL 中的特殊字符有特殊含义：

  • ? 分隔路径和查询参数
  • & 分隔多个参数
  • = 分隔参数名和值
  • # 标记锚点

如果参数值本身包含这些字符，不编码就会被误解析。比如搜索 "a&b"，如果不编码 &，服务器会把 & 当作参数分隔符，导致参数被截断。

哪些字符需要编码？

按 RFC 3986 标准，字符分为三类：

  • 保留字符（必须编码）：: / ? # [ ] @ ! $ & ' ( ) * + , ; =
  • 非保留字符（无需编码）：A-Z a-z 0-9 - _ . ~
  • 其他字符（必须编码）：中文、emoji、空格等非 ASCII 字符

URL 编码 vs Base64

两者常被混淆，但用途完全不同：

特性URL 编码Base64
目的让数据安全通过 URL 传输让二进制数据通过文本协议传输
输出长度原始的 3 倍（中文）原始的 133%
可逆性可逆可逆
典型场景URL 参数中的中文/特殊字符JWT、邮件附件、Data URL

各语言 URL 编解码示例

JavaScript

// 编码
encodeURIComponent("你好 world")  // "%E4%BD%A0%E5%A5%BD%20world"

// 解码
decodeURIComponent("%E4%BD%A0%E5%A5%BD%20world")  // "你好 world"

注意：encodeURI 不编码 :/?#&= 等字符（用于编码整个 URL），encodeURIComponent 编码所有特殊字符（用于编码参数值）。大多数情况下用 encodeURIComponent。

Python

from urllib.parse import quote, unquote

quote("你好 world")        # '%E4%BD%A0%E5%A5%BD%20world'
unquote('%E4%BD%A0%E5%A5%BD')  # '你好'

Java

import java.net.URLEncoder;
import java.net.URLDecoder;

String encoded = URLEncoder.encode("你好", "UTF-8");
String decoded = URLDecoder.decode(encoded, "UTF-8");

常见问题

空格编码为 %20 还是 +？

%20 是标准 URL 编码（RFC 3986）。+ 是 HTML 表单提交（application/x-www-form-urlencoded）的约定。现代开发中推荐使用 %20。

双重编码怎么办？

如果 URL 被编码了两次，字符会变成双重 %25：

原始:   你好
编码1:  %E4%BD%A0%E5%A5%BD
编码2:  %25E4%25BD%25A0%25E5%25A5%25BD

用 URL 编解码工具 多次解码即可修复。

中文 URL 对 SEO 有影响吗？

中文 URL 会被浏览器自动编码。Google 可以正常索引中文 URL，但建议在 sitemap 中使用编码后的 URL。百度也能处理中文 URL，但部分旧系统可能有问题。
