JSONPath 语法备忘

语法含义示例
$根对象$ 返回整个 JSON
.key子属性$.store
["key"]子属性（含特殊字符可用）$["my-key"]
[n]数组第 n 个（0 起始；负数倒数）$.list[0]、$.list[-1]
[n,m,k]多个索引$.list[0,2,4]
[s:e:step]切片（end 不含）$.list[1:5]、$.list[::2]
[*]所有子元素$.store.book[*]
..递归下钻 (descendant)$..price 找所有 price
[?(...)]过滤表达式$..book[?(@.price<10)]
@.key过滤里指当前节点[?(@.category=='fiction')]

过滤表达式支持 == != < <= > >= && ||，比较对象支持字符串、数字、布尔、null。
