支持的 cURL 参数

  • -X / --request — HTTP method
  • -H / --header — 请求头
  • -d / --data / --data-raw / --data-binary — 请求体（隐式 POST）
  • -u / --user — Basic Auth
  • -b / --cookie — Cookie
  • -F / --form — multipart 字段
  • -G / --get — 把 data 转 query string
  • --compressed / --insecure / -k — 各语言对应配置

解析在浏览器本地完成，cURL 内容（包括 token / cookie）不会上传任何服务器。
