JSON 转 TypeScript 类型生成器

粘贴 JSON 自动生成 TS interface——嵌套对象会拆成多个独立接口，数组里的不同 shape 会合并成 union，前端工程里很常见但手写很烦。

JSON 输入
TypeScript 输出
types.ts
// 粘贴 JSON 后会自动生成 TypeScript 类型...

这个工具能识别什么

  • 嵌套对象 — 自动提取成独立 interface，按字段名 PascalCase 命名（user → User），重名加数字后缀
  • 数组元素类型 — 同 shape 合并；不同 shape 自动 union（(Cat | Dog)[]）
  • 可选字段 — 数组对象里某 key 只在部分元素里出现，标 ?:
  • null 值 — 默认标 | null，可关闭
  • 大整数 — 超过 Number.MAX_SAFE_INTEGER 的字段会标注 // possibly precision loss
  • 非法 key — 含特殊字符或以数字开头的键会用 "key": Type 引号包裹

所有处理在浏览器本地完成，JSON 数据不会上传任何服务器。
